Independent audit: seed 917260443
--------------------------------
Four cases were generated using the first ranked valid primer design, actual
PCR amplicons and exported analysis templates, before inspecting their results.
Two single-reference cases and two three-homeolog cases each contain WT and
multiple concurrent indels. Deletion limits are 10 or 61 bp; large-homeolog
cut offsets are 223/358/498 bp. Deletions have variable physical origins on
both sides of the cut; selected cases contain two alleles of one net size.
Noise uses calibrated public negative-control residual blocks, rather than
arbitrary independent white noise. Those two public controls are not confirmed
technical replicates; this does not establish every real instrument's noise.

All 40 required reference x net-size groups (including eight WT groups) were
recovered above 1% conditional fraction; all 32 true edited groups were present.
No false group reached 1%. Maximum conditional total-variation error was
1.5363 percentage points; maximum reference-share error was 0.4403 pp.
One single-reference sample has a true deletion at the requested 61 bp limit;
its boundary QC warning remains, despite accurate numerical recovery.

This is NOT a clean false-positive result: nine false nonzero allocations
remained at approximately 0.11–0.76% conditional fraction. All were unresolved
by the engineering evidence assessment, but they remain numerical allocations
and cannot be called solved merely because of that label. All 32 true edited
groups met that evidence assessment. The main representative placement was
DNA-equivalent to the dominant truth allele in 27/32 groups; maximum mismatch
was 5 bp. Inserted DNA identity is not certified by these factorized mixtures.

After these outcomes, an exploratory full-null junction refit reduced some
small allocations but did not resolve the problem and made true-group evidence
less stable. It was rejected; the conditional-null source was restored exactly
to frozen-v5. Audit outcomes did not select any subsequent production change.
