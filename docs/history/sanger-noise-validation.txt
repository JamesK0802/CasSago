DISTRIBUTION / WORKFLOW UPDATE — 2026-10-31 (supersedes the historical component-noise results below)

Cause and changes
The former generator independently shuffled whole measured pulse-shape residuals.
This confused coherent context/read-position response drift with additive noise.
On identical six genotypes/primer products, removing that added residual gives
6/6 numerical passes, maximum conditional TV2.60pp; also removing context yield
reduces it to1.51pp. The previous0/6 is not evidence of calibrated real noise.
The corrected renderer interpolates measured pulse responses coherently and
separates block-correlated, intensity-scaled residuals estimated from247 matched
high-quality cycles in two public negative-control runs. They are not certified
technical replicates. This does not prove a complete real-instrument noise law.
No alternative engine, truth-specific inference or new user parameter was added.

A real cross-run control diagnostic exposed a separate inference problem: a
low-Phred WT tail was treated as a precise template. Relative inverse-variance
weights now account for WT local-context Phred uncertainty. Edited-sample Phred
is not used, because real mixtures can lower its call quality. Every sample cycle
remains in fitting and raw R2. Missing/all-zero or uniformly valued WT quality
leaves the former weighting unchanged. Inverse-variance weights are an operational
uncertainty model, not a calibrated posterior confidence interval.

Two workflow defects were also fixed: quantitative single-primer candidates need
72 usable upstream bases, and automatic exported/imported templates preserve
separate deletion/insertion limits (31bp deletion/30bp insertion tested), rather
than silently imposing the legacy mixed15bp cap. NGS behavior is unchanged.

Sanger noise and group-support update — 2026-10-31

One automatic analysis contract and the shared physical-junction mixture engine
are retained. No new public mode or parameter is introduced. All registered
sample cycles, both deletion directions and the requested indel range remain.

Changes
- WT control photometry: smooth read-strength trend and dye/neighbour effects
  can include a ridge-shrunk trinucleotide residual. The extra context model is
  used only if withheld WT-cycle prediction improves. It is never learned from
  the edited sample or truth fractions.
- Pooled length support: covariance uses cycle-block residuals, with the former
  IID estimate as a floor. Searching more possible junction origins requires
  stronger support for an additional length. Retained lengths are refitted
  without a fraction penalty. This is an engineering support rule, not a
  calibrated statistical confidence interval.
- Do not equate uncertain homeolog allocation with absence of an edit. A trial
  that zeroed weak reference-specific coefficients removed genuine components
  in empirical-component tests and was rejected. Individual homeolog allocation
  estimates remain numeric. Geometry QC checks the pre-selection active set too,
  so deleting an ambiguous alternative cannot manufacture a clean QC result.
- Sparse photometry design rows avoid multiplications by zero. Mathematical
  output is unchanged by this implementation optimization.
