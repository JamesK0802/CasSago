  weight by donor coverage. Avoid multiplying one isolated poor call into a
  whole +/-range row loss. Keep minimum row count/conditioning. Classic unchanged.
- SCF 2.x/3.x, unsigned 8/16-bit, big-endian, v3 modulo double-delta reader.
  Input detected by signature. Explicit size/offset/version/monotonic checks.
  All-zero SCF probability fields are absent quality, never invented Phred.
  Real ABI/SCF channels, positions and sequence match exactly in a paired fixture.
- Single QC now checks original-dye-space position residuals >0.20, alternating
  position edit differences >10 pp and upstream held-out R2 <0.80. The numerical
  thresholds match pooled checks. Shared rawSignalScore does not alter weights.
- Single wider-range check uses held-out positions: +5/+10 and up to30, train
  >=model count, valid>=30, held-out R2 gain>=.01, RMSE decrease>=15%, outside
  range fraction>=3%. Suggest range and fail QC; never silently change user range.
- Use control sequence for single reference; require target entry after copying.
  Single no longer demands a full-product assertion, since an aligned reference
  region is adequate. Pooled still requires complete actual products and primer.
