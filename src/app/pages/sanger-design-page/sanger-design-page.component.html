Method & references

Accepts full genomic or gene sequences (up to 2 Mb each; 8 Mb total), generates candidates around the required target windows, and checks binding across the full input. Shared-Sanger mode searches one identical A/C/G/T oligo across every input reference, requiring a single exact binding site in a shared orientation. Every required window must fit within the usable read range, with different distances to corresponding targets. Only the sequencing side must have different target distances. The optional common opposite primer completes the PCR pair; it is not an additional sequencing primer. Separate-reference mode designs individual PCR pairs with a configurable cross-binding mismatch screen.

Offset separation and WT sequence differences are design diagnostics. They do not prove that mixed edited reference traces can be decomposed. These design diagnostics are separate from trace fitting in the Sanger Analysis tab.

CHOPCHOP uses Primer3 and genomic mapping for primer design. This browser search screens the supplied references, not a whole genome. Shared designs check at most 600 primary primers, retain multiple partner options and return up to 300 pairs. Sanger results prioritize greater minimum unintended-site mismatch counts, then fewer near sites, usable WT signal differences for shared-Sanger candidates, and target coverage. PCR-only ranking is unchanged. Sanger coverage excludes at least the first 50 bp and the final 50 bp of the shorter of the configured read limit and predicted extension. The whole target window plus indel allowance must fit inside this usable region. Measured quality may require a larger exclusion.

Candidate generation and oligo checks follow principles used by Primer3 and Primer-BLAST; this browser implementation does not run either tool. SantaLucia 1998 supplies the Tm model. TIDE and Poly Peak Parser provide related trace-decomposition work, not validation of this proposed assay.

Separate-reference design also draws on the locus-specific design strategy described in PolyMarker; this prototype does not run PolyMarker.
